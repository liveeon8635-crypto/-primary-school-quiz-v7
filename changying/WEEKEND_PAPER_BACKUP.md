# 周末课纸质备用与课后补录

入口：老师打开原周末课堂控制页 →「纸质备用与课后补录」。沿用原课堂、班级、学生账号、题目和积分规则，不创建副本档案。

## 课前

1. 审核教案和题目，绑定正确班级，再下载该课堂的 ZIP。
2. 解压后逐份打印教师稿、学生练习、教师参考答案、故障接续记录卡和方格操作纸。整包含教师答案和 manifest，不能发给学生。
3. 对照原教案检查长阅读、例题和题目。系统保留数据库内的完整文字，并打包本课已关联的 PDF、DOCX、PPTX、文本及图片原文件（最多20份、合计30MB）。识别文字不能恢复丢失原图；几何题等必须核对原文件并提前备齐图和教具。
4. 学生卷、记录卡带原学生和原题编号及16位包版本。教案、题目、附件或班级变化后重新下载、打印；旧版记录会被拒绝，不能强行套到另一题或学生。

## 故障时

在纸卡记下实际时间、环节、课件页码、练习题号、纸质用时和已完成内容，沿原课纸上继续。记录原答案、提示级别及答卷编号。文件本身无网络依赖，但必须课前下载、解压并打印。本功能不提供浏览器断网保存、自动同步或 CSV 导入。

恢复联网、课堂尚未结束时，可选原环节／页码并点击「恢复到所选环节／页码」。仅知识介绍和例题讲解使用课件页码；练习按原题号接续。不会新建课堂，不会回填或重置历史计时。实际纸质时长保留在记录卡。

## 课后

1. 整节课完成后结束原课堂；全程纸上完成的原计划课堂也可用「纸质课已完成：结束原课堂」。
2. 填写纸卡版本、原学生、原题、原答案（选择题选项；文字题原文或 JPEG/PNG 答卷照片≤3MB）、提示级别、带时区的实际作答时间、故障原因／答卷编号。教师对文字／照片题选正确、部分正确或需订正。一次保存一条原始答题记录。
3. 已有线上或纸质答案不会被覆盖，相同重试不重复记录；冲突请到原答案／批改区核对。补录写回原答题表、学习证据及错题本，不直接发积分。原课堂档案和原结算会纳入已批改文字题。
4. 先确认所有纸卡补录、所有文字／照片答案批改完，再使用原积分结算。结算仍只能一次；结算后禁止新增改变积分依据的补录。不能恢复已结束课堂为进行中。

## 人工验收（尚需真实课堂执行）

- 用含长阅读和图形原文件的真实教案、两名不同学生、选择与文字／照片题创建测试课堂，下载并打印。核对全文、分页、原图、题数和答案隔离。
- 上课中关闭网络及投屏设备，在纸上接续一题，记录环节／页码／题号和时间。不要在断网时依赖网页提交。
- 恢复网络，回到原课堂原环节；结束课堂后分别为两名学生补录，上传照片并批改，核对原课堂答案和档案。
- 分别登录两名原学生账号，确认只看到自己的学习记录、错题及私人照片；核对错题可见、原线上答案未变。
- 重复提交同一条、尝试换另一学生／过期版本、结算后再新增答案，确认重复不增加、越界／过期／已结算均拒绝；核对积分账本只结算一次。
- 在现代浏览器及真实 iOS 12.5.8 Safari 上分别检查展开面板、下载／打印、触摸选择、上传照片、恢复位置和补录。自动化语法测试不等于实机兼容验收。

自动化覆盖真实应用路由与原档案／错题／积分查询、教师和学生权限、版本、照片、时间、重复与覆盖保护，以及切换学生和题目的草稿隔离。
