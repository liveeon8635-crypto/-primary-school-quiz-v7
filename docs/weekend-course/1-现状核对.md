# 1. 现状核对(周末课,设计稿,未改代码)

## 可直接复用
| 能力 | 位置 | 用法 |
|---|---|---|
| 学期框架 | `teaching_programs`(学校/年/学期/年级) | 每科一个 program,下挂 18 课 |
| 课时 | `teaching_lessons`(subject、lesson_no、unit、core_target、duration_min=120、examples_json、ppt_json、closure_training、published) | 扩成 18 课;教案 AI 生成后老师审改 |
| 分级题 | `teaching_questions`(stage、level C/B/A、knowledge、options、explanation) | 保留作题源;课堂内不再按档派题 |
| 作答记录 | `teaching_adaptive_sessions` / `teaching_attempts` | 课堂数据来源之一 |
| 作文 | `teaching_essays` | 语文作文环节 |
| 课堂会话 | `classroom_sessions`(lesson_id、status、current_segment_id)`classroom_segments`(knowledge_key、order_no、baseline/postcheck_accuracy)`classroom_presenter_turns`(学生上台讲解邀请)`classroom_events`(事件流水) | 7 环节、强带弱、档案的底座 |
| 大屏与锁屏 | `changying/web/v1_classroom_live_board.py` | 只显示放行内容 |
| 积分 | `point_rules` / `point_ledger`(含冲正) | 进步分、团队分、小老师分直接记账 |
| 错题/学情 | `wrong_question_records`、`homework_ai_knowledge`、学情统计 | 进步指标基线、薄弱点补回 |

## 缺口
1. 课堂会话只能从"作业"创建(`/teacher/assignments/{aid}/classroom-session`),没有"从课时创建";segment 按知识点切分,没有 7 环节概念。
2. `ppt_json` 只是页标题列表,无页类型/内容。
3. 无提示阶梯(提示内容、级数、用量记录)。
4. 无知识点讲解卡片实体;学生端无搜索。
5. `presenter_turns` 只记录邀请与状态,未关联"被讲学生 + 巩固题结果"。
6. 无课堂档案汇总、无家长简报。
7. 无学校进度表与周次对应。

## 复盘功能改动范围
- `v1_classroom_review.py`、复盘讲义:保留生成逻辑,作为环节 5 素材。
- 周末课入口并入控制条;大班/晚托入口保持不变。

## 约束
- 学生页只读带(`v1_classic_unified_top.py`)禁止业务写入;学生要提示/作答走现有 API 路径,不新增写入到只读带。
- 新表需走 `register_*_tables` 模式并带 school_id 隔离;`.sql`/requirements 变更 PR 边界检查会变红,手动合并。
- AI 失败需有预生成兜底。
