# 语文周末课课型与流程（当前实现）

## 课型和流程

语文课在周末课进度表中显式选择“阅读课”或“作文课”。选择保存在课程工作流记录中，带修订号；旧语文课没有记录时显示“待选择课型”，创建课堂会被拒绝。数学课仍使用原七环节。

阅读课和作文课各有六个 120 分钟流程：

| 阅读课 | 作文课 |
| --- | --- |
| 点名与回顾 | 点名与回顾 |
| 短文阅读 | 范文导览 |
| 长文阅读 | 看图写话 |
| 考点总结 | 技法梳理 |
| 综合练习 | 随堂练习 |
| 课后反馈 | 课后反馈 |

新语文课堂保存所选课型、课程修订号及课程内容快照。更改课程课型不会重解释已创建的课堂；上线前的历史课堂没有新快照时继续使用旧七环节行为。

## 整包字段

沿用 `/teacher/weekend/lessons/import` 的结构化 JSON 整包格式；`items[]` 中单课可以声明：

```json
{
  "courseType": "reading",
  "readingPlan": "阅读材料原文",
  "writingPlan": "作文主题或任务"
}
```

语文课需先在工作栏保存课型；整包声明的 `courseType` 与工作栏不一致时拒绝导入。`readingPlan` 和 `writingPlan` 是现有课程字段，不会自动拆成已审核的节点。原有整包字段继续有效；结构化导入不调用外部 AI。

## 目前已实现

- 课型选择、保存、刷新读取、修订冲突保护和待选课型阻断。
- 数学七环节保留；语文课堂按课型使用六环节并冻结课堂快照。
- 教师课件选择器从课型流程生成环节列表；数学仍使用原选择器。
- 现有文字/照片作答接口按数学第 4 环节或语文第 5 环节校验开放时机。
- DOCX 内嵌 PNG/JPEG 会保留源文件名、部件名和原始字节 SHA-256。大图生成最长边 2200 像素的 JPEG 审核预览，原始教案不改写；无法解码或超过预算的图会计入遗漏数。
- 图片预览随教案事务保存为“待确认”素材；教师工作栏可查看来源、绑定阅读/作文环节或忽略。待确认素材会阻止创建课堂，教师专用接口不向学生返回素材。
- 普通语文文档的单次和批量导入使用本地草稿路径，不调用外部模型；当前尚未自动拆分文章和习题，必须由教师核对。

## 当前限制（不得据此宣称全流程验收通过）

- 结构化整包尚无文章/图片/音频/视频/题目/答案/解析之间的独立素材关系、识别依据、置信度和待确认项审核模型。
- 现有课程字段不足以区分教师答案版与学生无答案版；学生端文章节点和长文题目/提示/解析逐步开放尚未完成。不要把教师版整份 `readingPlan` 作为学生内容源。
- 已确认素材目前仍未自动生成或绑定互动课件页面，长文的幻灯片/视频/音频和题目提示/答案/分步解析的课堂逐步开放未完成；不得把素材审核状态称为课件审核通过。
- 已只读提取桌面上的第十二次课教师版和学生版：分别提取 7205、6072 字，两份文件各识别并保留 4 张图片预览，遗漏数为 0。这只是提取验证；配对导入、防泄露和表格完整性尚未验收。
- 作文范文、图组、方法组、练习主题的素材编辑与绑定界面尚未完成。
- 多班课堂隔离只冻结课程快照；语文全流程任务、已取消预约重约、勘误层、教师反馈草稿发布及两班并行课堂的端到端验收仍需补齐。

任何导入成功提示都必须同时区分“已提取”“待确认”“已审核”和“已可用于课堂”。原始文件只读保留；未识别的内容应进入可见待确认状态，不能静默丢弃。
