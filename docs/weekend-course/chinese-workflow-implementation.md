# 语文周末课课型与流程（当前实现）

## 作文开发分支 2026-11-23

新增作文专用本地素材清单、审核编辑、图文关联和冻结课堂接口，入口为备课工作栏“作文素材与审核”。数据复用已有 lesson_import_pairs.meta_json 与 weekend_session_workflows.lesson_json，不新增表、不回填历史课堂；备课修改保留历史，重新导入保留原导入记录。写作任务复用文字/照片提交版本与批注接口。

第13次真实原件提取出11张图片、1张5行表格；正文和图片锚点保留，识别18个方法候选、17个范文分行候选、1个主题候选，其余待确认。逐张查看原件图片后确认它们主要是文字截图与导图，不能直接视为范文场景配图。原始导入在缺项时被阻断。本分支的 `assets/writing_lesson13/` 保存4张明确标为“AI生成”的补图及来源说明；使用原件和这些补图，在隔离数据库中实际完成导入、逐项确认/忽略、图文绑定、审核、创建课堂、学生照片提交、教师批注与反馈发布。补图仍须教师在正式使用前核对。

本地 Chromium 已对作文备课、教师课堂和学生课堂页面做390px视口实际渲染与交互检查。课件选择器与作文课堂从同一六环节定义取值；作文课堂按环节切换，范文图片依绑定关系跟随段落。预约日期沿用备课工作栏的计划日期，已创建的课堂保持待开状态直至教师开始。仍待教师对 AI 补图及范文自然段作教学核对、Safari12 实体设备和线上角色操作检查。本分支未部署，不表示可上线。

## 阶段二阻断补丁（未部署）

- 新语文课堂在创建及开始时均由服务端检查：已选课型、已有教案、无待确认导入素材、六环节均有实际课件、对应页全部审核通过、任务与答案绑定未变化。总表的 approved 只代表曾有页面通过，不作为开课依据；requireReady=false 不能绕过语文门槛。
- 状态接口分别返回 coursewareGenerated、coursewareApproved、canStart、startReasons、stageReadiness。这里仅检查现有结构中的缺项与审核；文章数量、精确媒体关系、配对原件识别的完整验证须待数据方案获批后施工。
- 修改课型撤销当前课件审核；未开始课堂再次检查，进行中课堂的课型快照保留。现有课件仍按课程读取，修改会影响进行中课堂的可展示课件；完整冻结课件版本待下一阶段，当前不要在授课中修改备课内容。
- 普通数学/语文教案默认本地导入，结构化整包继续本地解析。外发教案使用独立 TEACHING_DOCUMENT_AI_EGRESS_APPROVED 授权（默认关闭），学生数据开关不能替代；携带学生归属时还需通过原学生授权检查。本补丁不设置任何生产环境变量。
- 回退：回滚应用提交；无新增表、迁移或数据回填。回滚会重新引入本次修复的开课和外发风险，不建议回退后继续创建语文课堂。

## 课型和流程

语文课在周末课进度表中显式选择“阅读课”或“作文课”。选择保存在课程工作流记录中，带修订号；旧语文课没有记录时显示“待选择课型”，创建课堂会被拒绝。数学课仍使用原七环节。

阅读课和作文课各有六个 120 分钟流程：

| 阅读课 | 作文课 |
| --- | --- |
| 点名与回顾 | 点名与回顾 |
| 短文阅读 | 范文导览 |
| 长文阅读 | 看图写话 |
| 考点总结 | 技法梳理 |
| 综合练习 | 随堂练习 |
| 课后反馈 | 课后反馈 |

新语文课堂保存所选课型、课程修订号及课程内容快照。更改课程课型不会重解释已创建的课堂；上线前的历史课堂没有新快照时继续使用旧七环节行为。

## 整包字段

沿用 `/teacher/weekend/lessons/import` 的结构化 JSON 整包格式；`items[]` 中单课可以声明：

```json
{
  "courseType": "reading",
  "readingPlan": "阅读材料原文",
  "writingPlan": "作文主题或任务"
}
```

语文课需先在工作栏保存课型；整包声明的 `courseType` 与工作栏不一致时拒绝导入。`readingPlan` 和 `writingPlan` 是现有课程字段，不会自动拆成已审核的节点。原有整包字段继续有效；结构化导入不调用外部 AI。

## 目前已实现

- 课型选择、保存、刷新读取、修订冲突保护和待选课型阻断。
- 数学七环节保留；语文课堂按课型使用六环节并冻结课堂快照。
- 教师课件选择器从课型流程生成环节列表；数学仍使用原选择器。
- 现有文字/照片作答接口按数学第 4 环节或语文第 5 环节校验开放时机。
- DOCX 内嵌 PNG/JPEG 会保留源文件名、部件名和原始字节 SHA-256。大图生成最长边 2200 像素的 JPEG 审核预览，原始教案不改写；无法解码或超过预算的图会计入遗漏数。
- 图片预览随教案事务保存为“待确认”素材；教师工作栏可查看来源、绑定阅读/作文环节或忽略。待确认素材会阻止创建课堂，教师专用接口不向学生返回素材。
- 普通语文文档的单次和批量导入使用本地草稿路径，不调用外部模型；当前尚未自动拆分文章和习题，必须由教师核对。

## 当前限制（不得据此宣称全流程验收通过）

### 2026-11-21 阻断修复（未完成全流程验收）

- 自动生成只写课件草稿，不再代替教师审核；补充生成保留已有课件。
- 语文缺少环节素材时保持缺项，不用其他环节的教案填充。原文草稿按容量分页，超出容量拒绝生成，不把末句作为答案。
- 课件页常显六环节状态和审核操作；整体预览默认收起，空环节明确标出缺少素材。AI 与课堂维护收纳到“更多操作”。
- 图文幻灯片不自动转为学生作答题。大屏幻灯片响应只携带当前页，其他页保留空对象以维持页码契约；翻回前页后后页内容不再返回。
- 上述修复不构成文章、题目、素材关系审核或完整开课校验。既有自动审核数据没有批量撤销；进行中课堂、历史数据均未执行迁移或回填。

- 结构化整包尚无文章/图片/音频/视频/题目/答案/解析之间的独立素材关系、识别依据、置信度和待确认项审核模型。
- 现有课程字段不足以区分教师答案版与学生无答案版；学生端文章节点和长文题目/提示/解析逐步开放尚未完成。不要把教师版整份 `readingPlan` 作为学生内容源。
- 已确认素材目前仍未自动生成或绑定互动课件页面，长文的幻灯片/视频/音频和题目提示/答案/分步解析的课堂逐步开放未完成；不得把素材审核状态称为课件审核通过。
- 已只读提取桌面上的第十二次课教师版和学生版：分别提取 7205、6072 字，两份文件各识别并保留 4 张图片预览，遗漏数为 0。这只是提取验证；配对导入、防泄露和表格完整性尚未验收。
- 作文范文、图组、方法组、练习主题的素材编辑与绑定界面尚未完成。
- 多班课堂隔离只冻结课程快照；语文全流程任务、已取消预约重约、勘误层、教师反馈草稿发布及两班并行课堂的端到端验收仍需补齐。

任何导入成功提示都必须同时区分“已提取”“待确认”“已审核”和“已可用于课堂”。原始文件只读保留；未识别的内容应进入可见待确认状态，不能静默丢弃。
