# 3. 口径文档(默认值,上课后调)

**完成率** = 本节核心题中"独立或经提示后做对"的题数 / 核心题总数,按人算,班级为三人平均。
**提示依赖** = 学生做对的题所用最高提示级数的平均(0=未用,1-3)。

## 进步(个人,仅与自己比)
基线 = 该学生同学科最近 3 次课的均值;不足 1 次则为首次课,只给参与分。
- 正确率进步 ≥ +10 个百分点 → +2 分
- 提示依赖下降 ≥ 0.5 级(仅做对的题计入)→ +2 分
- 补回上次被标记的薄弱知识点(本节该点做对且未用 3 级提示)→ +3 分/个,每节最多 2 个
- 单节进步分封顶 6;退步不扣分;缺课不得分且不影响基线;全程未作答不计。

## 强带弱
1. 练习后按完成率排序,仅老师可见。
2. 老师点选小老师(系统建议完成率最高且本节未讲过者);讲解题取低完成学生做错的题。
3. 讲后被讲学生做同知识点换数字的巩固题。
- 小老师分:被讲学生巩固题做对 → +2;未做对 → 0(不扣)。
- 被讲学生:巩固题做对 → 计入个人进步(正确率口径),不重复发分。
- 小老师轮换:同一人连续两节被指定,系统提醒老师。

## 团队目标
- 达标线:本节"巩固后完成率" > 上一次课"巩固后完成率"(首次课无上次,只记录)。
- 达标 → 全员各 +2;提升每 +10 个百分点再 +1,团队分封顶 +4。
- 全对:改为挑战题,目标变"全员独立完成";全错:不触发强带弱,只记参与。

## 提示阶梯
- 数学:1 方向、2 第一步、3 完整讲解。
- 语文阅读:1 找关键句、2 概括段意、3 完整思路;作文:1 审题、2 提纲、3 范例片段。
- 提示内容 AI 预生成、老师审核后生效;课堂内 AI 实时生成仅作补充,失败回退预生成。
