# 实施顺序

1. 锁定源码与浏览器基线。
2. 共享色彩、布局与焦点样式接入现有渲染入口。
3. 分别检查 V1、全部功能、Classic、晚托、周末和大屏。
4. 用现有角色和业务测试复查数据及行为，再做截图对照和 Safari 脚本校验。
5. 在独立草稿 PR 收集相同提交下的 CI。回滚可关闭新增样式或回退施工提交。
