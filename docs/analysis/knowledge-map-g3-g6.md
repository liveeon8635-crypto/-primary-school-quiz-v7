## 5. 验收步骤

### 老师

1. 进「知识地图」→ 建图 → 应能看到三个模板：三、五、六年级上册数学
2. 建三年级 → 核对单元数与顺序是否和教材一致（10 个单元）
3. 建六年级 → 同上（9 个单元）
4. 点开任一知识点 → 看学习目标、前置、常见错误是否合理；不对的直接编辑
5. 配题后回来看该节点是否变成「可小测」（题量 6、三档各 2）
6. 确认无误后再点「发布知识地图」——**在此之前学生看不到任何数据**

### 学生

1. 三年级学生登录 → 知识地图 → 只看到三年级地图，看不到五年级内容
2. 点一个已配题且已发布的知识点 → 出小测（3–5 题），按首次作答记录掌握度
3. 未发布/未配题时 → 应看到"还没有可练习的内容"，不显示任何掌握度
