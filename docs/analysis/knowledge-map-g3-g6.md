- 多位数乘一位数：口算乘法 / 不进位 / 一次进位 / 连续进位 / 乘数中间或末尾有 0 / 用乘法估算解决实际问题

- 线和角：认识线段射线直线 / 用圆规比较线段长短 / 认识角和直角 / 角的分类
