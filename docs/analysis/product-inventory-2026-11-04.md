## 产品主线
教材与课程资料 → 老师备课/审核题目 → 课堂、周末课、晚托、应试练习 → 学生作答/老师核验 → 学生连续档案与学习证据 → 老师审核报告 → 家长查看。

题库、学生身份、正式提交和教师审核是共享底座。晚托求助中的互动回答及圆面积补救确认只服务辅导，不作为正式成绩或地图掌握度证据。

## 功能总表
| 功能模块 | 老师/管理员能做什么 | 学生/家长得到什么 | 状态与前提 |
|---|---|---|---|
| 账号与班级 | 管理本校账号、学生、班级和归属 | 按身份进入对应页面 | 既有基础能力；数据按学校及接口归属限制 |
| 题库与组卷 | 导入题目、AI辅助出题、审核、组卷、布置 | 完成选择、判断、填空、计算和开放题等 | 题型决定程序核对或老师批改 |
| 试卷导入与组合 | 独立试卷导入、组合路由已接入 | 使用布置的试卷 | 本次核对注册调用，未逐项实测导入格式 |
| 普通作业与错题练习 | 查看提交、批改、布置针对性练习 | 作答、查看按规则开放的反馈、错题再练 | 正式结果进入共享提交记录 |
| 学生连续档案 | 查看成绩、历史班级、薄弱点、跟进记录 | 同一学生积累长期记录 | 换班、升年级不应复制档案 |
| 学习证据 | 记录与查看作答、独立完成、保持、迁移等证据；阶段对比 | 形成有依据的成长记录 | 不凭一次讲解自动下长期能力结论 |
| 周末课备课 | 导入/编辑教案、AI出习题、审核、标考点、标课后题 | 使用老师确认的课程内容 | 开课前需满足教案和已审核习题条件 |
| 周末课上课 | 控制环节、大屏讲解、逐题公布答案、查看作答 | 平板练习、提示、课堂参与 | 大屏、教师控制页和学生页分别使用 |
| 周末课照片预批 | 查看原图、识别内容、核对依据；修正识别；重试；核验采用 | 原答案保留，老师确认后成为正式批改 | 识别配置、学校授权及限额需满足；失败仍可手工批改 |
| 周末课反馈 | 全班生成草稿、逐份修改、发布、导出Word | 家长看到孩子的考点表现、回家任务及与自己上次比较 | 草稿需老师核对；课后未交题单列 |
| 打印与补录 | 教师版/学生版Word、纸质备用、课后补录 | 断网时仍能纸上完成 | 补录口径要与线上作答区分 |
| 知识地图 | 建教材地图、前置关系、配题、分难度、发布、班级诊断及巩固 | 入门诊断、知识点小测、个人地图 | 学生读取已发布且匹配年级的地图；题量不足不硬下结论 |
| 地图教材模板 | 五年级既有模板；三、六年级2026人教版上册数学模板 | 对应年级可配置地图 | 模板存在不代表学校已经创建、配题、审核、发布 |
| 地图题目草稿 | 为节点准备、查看和导入题目草稿 | 审核并纳入地图后用于练习 | 最新改动只对实际有草稿的节点显示导入按钮 |
| 应试专项 | 建考试目标、范围、模拟卷、失分点分析、专项练习、再测、发布报告 | 限时模拟、定向练习、家长提分报告 | 依赖可用题库/地图及考试目标；不做学生排名 |
| 日常互动课堂 | 课堂执行、随堂检测、学生讲题、复盘、课堂讲义版本发布 | 参加课堂互动、查看当前发布讲义 | 相关执行/快测/复盘/讲义路由已接入；本次未逐页验收 |
| 晚托作业清单 | 导入学校通知、整理并发布作业清单 | 查看今天作业并勾选完成 | 需要晚托开关及相应AI配置 |
| 晚托时间管理 | 发布时设置全部科目共用的总时限；查看每人用时及超时 | 第一项勾选后开始计时，显示剩余时间 | 留空不限时；到时可继续完成，不强制收卷 |
| 晚托拍题求助 | 查看求助、AI引导和学生作答过程，接手处理 | 拍照/文字求助、逐步小问题、提示、自己填最终答案 | 可验算步骤由程序核对；不可验算内容不强行判数值对错 |
| 晚托与地图联动 | 参考学生已会/薄弱前置知识、考试范围；安排巩固 | 从已会处讲起，再做审核过的同类题 | 地图需发布；无可用新题不应留下无效小测入口 |
| 圆面积固定补救 | 查看卡点、已用帮助、当前状态摘要 | 六年级圆面积可选基础检查、固定图示、两轮补救及求助老师 | 普通求助不增加必选步骤；确认题只记辅导过程；单位仅辅导内检查 |
| 知识点讲解卡片 | AI起草、老师审核 | 搜索和查看审核过的知识讲解 | 不能把未审核草稿当已发布教学内容 |
| 教学资料与课件模板 | 上传资料辅助备课、复用互动课件模板 | 不同课程使用可复用内容 | 不等于所有资料均可跨学校共享 |
| 家长端 | 建立和维护家长—孩子关联、发布可见报告 | 查看自己孩子的作业、成绩和已发布反馈 | 不展示其他孩子或老师内部备注 |
| 往期教学与升年级衔接 | 查询历史、查看衔接事实与计划、教学周期 | 延续已有学习记录 | 不自动修改学生年级和班级；工作模式不等同新增权限 |
| 产品帮助与反馈 | 功能问答、导航、提交反馈、跟踪处理结果 | 查找入口、反馈问题 | 已接入帮助/反馈路由；不是教学评分入口 |
| 实操沙盒 | 角色学习、模拟既有基础流程、观看模块导览 | 学习各角色操作 | 部分模块仅导览，不能把导览当已完成真实教学验收 |
| 运维与用量 | 查看调用用量及失败类别 | 支撑故障排查 | 最新主线已按功能和错误归类失败调用；接口200不代表识别文字完全准确 |

## 角色使用顺序
- 老师：班级与学生 → 题库/课程资料 → 备课和审核 → 上课/发布作业 → 批改核验 → 档案/反馈 → 发布给家长。
- 学生：当前课堂/今日作业 → 作答或求助 → 查看提示与反馈 → 做老师审核的新题验证。
- 家长：关联孩子 → 查看已发布报告和作业情况 → 了解在家配合任务。
- 管理员：本校账号、学校与AI相关设置、用量维护。账号身份不意味着可跨学校读数据。

## 功能边界与验收提醒
- “AI识别”是抄录；预批建议必须经老师核验才成为正式批改。
- “看过讲解/辅导确认通过”与“独立小测形成掌握度”分开。
- 有页面、接口和测试文件，不等于学校已开开关、配齐题库和完成真机验收。
- 文档写“只调用一次AI”应理解为普通讲题路径；既有验算失败重试策略可能产生额外调用。
- 未对最新main运行全量CI、本校数据配置、每个角色权限、所有科目、旧iPad或全部课堂流程作完整审计，不宣称全站验收通过。

## 建议的现场验收顺序
1. 题库→布置→学生提交→老师批改→学生档案，先通基础链。
2. 周末课教案/审核题→开课→大屏/平板→照片批改→反馈发布→家长查看。
3. 发布匹配年级的地图→学生诊断/小测→老师班级视图与巩固。
4. 晚托清单→总时限→勾选开始→超时仍可完成→老师查看实际用时；再试拍题和圆面积补救。
5. 应试目标→模拟→专项→再测→报告发布。
6. 日常课堂、往期教学、衔接、沙盒和帮助入口分别核验，检查角色可见范围。
